# 04. TERAZAWA STUDIO 専用 AI編集支援ガイドライン (AI Assistant Guide)

## 1. 基本方針：API-Key-Free ＆ 人間介在型（Human-in-the-Loop）運用
本システムでは、外部AIのAPIキーをプログラム内に組み込みません。
- **理由**: APIキーの漏洩リスク、トークン従量課金コスト、将来の仕様変更による停止を完全排除するため。
- **運用方法**: 事務所スタッフがブラウザ上の対話型AI（ChatGPT, Claude, Gemini等）に本ガイドのプロンプトを貼り付け、出力されたテキストやJSON差分を TERAZAWA STUDIO（または Pages CMS）に反映・確認して保存します。

---

## 2. AI利用時の絶対禁止事項（Guardrails）
1. **税務・法律上の断定表現の禁止**:
   「100%節税できる」「絶対に税務調査に入られない」等の虚偽・誇大表現、税理士法に抵触する表現をAIに生成させないこと。
2. **無検証での本番反映禁止**:
   AIが作成した文章は、必ず寺澤代表または担当者が目視確認してから「承認して保存」を行うこと。
3. **個人情報・機密情報の入力禁止**:
   実在する顧客企業の決算数値や相談者の氏名・電話番号をAIのプロンプトに入力しないこと。
