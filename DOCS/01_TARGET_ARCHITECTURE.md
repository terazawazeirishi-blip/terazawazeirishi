# 01. 目標アーキテクチャ設計書 (Target Architecture)

## 1. プロジェクト目標：TERAZAWA WEBSITE STUDIO
Google Sites / Wix のような直感的操作性と、GitHub Pages の堅牢性・コスト0円（APIキー不使用）を両立したノーコードホームページビルダー。

## 2. システム階層モデル
┌────────────────────────────────────────────────────────┐
│             TERAZAWA WEBSITE STUDIO (Visual Builder)   │
│  - 画面上での直接テキスト編集 / 画像差し替え / ブロック入替 │
└──────────────────────────┬─────────────────────────────┘
                           │ Single Source of Truth
┌──────────────────────────▼─────────────────────────────┐
│                 正本データ層 (content/*.json, blog/*.md) │
│  - site_images.json, home_texts.json, services.json等   │
└─────────────┬───────────────────────────┬──────────────┘
              │                           │
┌─────────────▼──────────────┐ ┌──────────▼──────────────┐
│   Pages CMS (標準CMS運用)   │ │  公開サイト (GitHub Pages) │
│ - フォーム入力による確実な更新 │ │ - main.js による安全レンダリング │
└────────────────────────────┘ └─────────────────────────┘

## 3. 基本方針
1. Zero-Fail 原則: JSやCMSがダウンしても静的HTML/SVGフォールバックで表示が絶対に崩れないこと。
2. APIキー完全不使用: 認証はGitHub App / OAuth標準のみ。
3. 既存デザインの完全保全: アテナ税理士法人準拠の品格（配色・タイポグラフィ・余白・Sticky）を不可侵とする。
