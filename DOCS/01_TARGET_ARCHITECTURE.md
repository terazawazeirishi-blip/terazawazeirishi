# 01. 目標アーキテクチャ設計書 (Target Architecture)

## 1. 全体ビジョン：TERAZAWA WEBSITE STUDIO
Google Sites / Wix と同等の「ブラウザ上の直感的なビジュアル直接編集」を、GitHub Pagesの「完全無料・高堅牢性・Zero-Fail」を維持したまま実現する。

## 3. 設計上のコア原則
1. **Zero-Fail原則**: CMSやJSの読み込みが遅延・停止した場合でも、HTML内に記述された初期値（静的フォールバック）が美しく表示され、サイトが絶対に白画面にならない。
2. **API-Key-Free**: 外部課金APIキー、シークレットトークンをクライアントサイドに一切埋め込まない。
3. **Athena Design完全準拠**:
   - CSS変数（`:root`）の先頭宣言
   - 巨大英字透かし（`TERAZAWA`）の中央配置
   - 象徴イラストの下部グラデーションマスク（`mask-image`）
   - 左固定・右スクロール（`Sticky`）仕様
   - 常駐型フローティングCTA（`#A08C4A`）の維持
