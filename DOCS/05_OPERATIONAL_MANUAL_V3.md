本マニュアルは、専門知識（HTMLやプログラミング）を使わず、ブラウザだけで日常の全業務を完結するための手順書です。

## 2. 写真・画像の変更手順（コード不要・1〜2分で完了）

1. ブラウザで **Pages CMS**（`https://app.pagescms.org/`）を開きます。
2. 左メニューの **「📷 サイト全画像スロット管理」** をクリックします。
3. 変更したい項目（例: `rep_keiko` 代表写真、`service_01` サービス写真など）を探します。
4. **「ファイルを選択」** を押し、PC内の画像を選んでアップロードします。
   - ※推奨形式: WebP または PNG（正方形または横長）
5. 右上の **「Save」** ボタンを押します。
6. **完了**: 約1〜2分後、本番サイトを開いて `Ctrl + F5`（強力再読み込み）を押すと写真が切り替わります。

---

## 3. 税務・経営コラムの新規投稿・編集手順

1. **Pages CMS** の左メニュー **「📝 税務・経営コラム」** をクリックします。
2. 右上の **「New entry」** をクリックします。
3. 各項目を入力します：
   - **記事タイトル**: 読者の目を引く見出し（35文字以内推奨）
   - **公開日**: カレンダーから選択（例: `2026-11-04`）
   - **カテゴリー**: 「税務調査対策」「クラウド会計・DX」などから選択
   - **サムネイル画像**: 記事の見出し画像を選択
   - **本文**: 見出しや太字を使って記事を入力
4. 右上の **「Save」** を押します。
5. **完了**: 自動的に `blog/index.html` の一覧および詳細ページが生成され、本番サイトへ掲載されます。

---

## 4. ホームページの文章直接編集（TERAZAWA STUDIO）

1. ブラウザで **TERAZAWA STUDIO**（`admin/studio.html`）を開きます。
2. 上部のプルダウンから編集したいページ（トップ、サービス、料金等）を選びます。
3. **文字の変更**:
   - キャンバス内の文章をクリックすると、キーボードで直接文字を書き換えられます。
   - 右側の「プロパティパネル」からリンク先URLやボタン文言も変更可能です。
4. **セクションの並び替え**:
   - 左側の「セクション階層」にある「↑」「↓」ボタンを押すと、セクションの順番が瞬時に入れ替わります。
5. **スマホ表示の確認**:
   - 上部の「📲 スマホ (390px)」を押すと、画面がスマートフォン幅に縮小し、崩れがないか確認できます。
6. **保存**:
   - 右上の **「💾 保存・確認」** を押します。
   - 変更差分を確認し、**「承認して保存」** を押せば完了です。

## 5. 料金プラン改定・FAQ（よくある質問）追加手順

### 料金プランの変更
- **Pages CMS** の **「💰 料金案内・スポット報酬」** を開き、月額顧問料や決算料の数字を打ち替えて「Save」を押します。

### よくある質問の追加
1. **Pages CMS** の **「❓ よくある質問（FAQ）」** を開きます。
2. 「Q&A リスト」の **「Add item」** を押します。
3. `id`（例: `faq-06`）、`question`（質問）、`answer`（回答）を入力します。
4. 右上の **「Save」** を押すと、本番サイトのアコーディオンに新しい質問が自動追加されます。

## 6. お問い合わせ発生時の対応フロー

1. お客様がサイトのフォーム（`contact.html`）から相談を送信。
2. **Google Apps Script（GAS）** が即時自動稼働：
   - Googleスプレッドシートの最終行に「未対応」ステータスで自動記録。
   - 寺澤代表へメールで通知、お客様へ受付完了メールを自動返信。
3. 寺澤代表または担当者が内容を確認し、原則1営業日以内にお客様へ電話（`0969-22-1166`）またはメールで返信。
4. 対応完了後、スプレッドシートのステータス列を「対応中」または「完了」へ更新します。

## 7. 万一のトラブル・誤操作時の即時復元（ロールバック）

### 方法A: TERAZAWA STUDIO のバックアップ復元（最も簡単）
1. `admin/studio.html` の左下にある「バックアップ復元」のファイル選択を押します。
2. 以前保存した `backup_home_xxxx.json` を選択します。
3. 「復元しますか？」でOKを押すと、画面が過去の正常な状態へ一瞬で巻き戻ります。
4. 「💾 保存・確認」を押して再保存します。

### 方法B: GitHub Web画面からのコミット取り消し
1. GitHubリポジトリのコミット履歴（`Commits`）を開きます。
2. 正常だった直前のコミットを探し、`Revert` ボタンを押します。
3. 自動的に安全な前のバージョンへ復旧デプロイが行われます。
